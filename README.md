# Road & River Management System

An offline-first civil infrastructure management system
designed for municipal public works operations in Japan.

## Overview

This project aims to support municipal infrastructure
maintenance through centralized facility records,
GIS-based case management, inspection histories,
and long-term infrastructure cost analysis.

## Features (Planned)

- Road, bridge, river, park and agricultural facility management
- GIS-based case management using Leaflet
- Bridge inspection scheduling and reminders
- Maintenance, inspection and construction histories
- Boundary confirmation and occupancy permit management
- Document management
- Infrastructure lifecycle cost analysis
- GIS data export and interoperability

## Technology Stack

- Python 3.14
- Flask
- SQLite
- DuckDB
- Leaflet
- GeoPandas
- Shapely

## Architecture

The system is designed for offline environments.

- SQLite: Operational database
- DuckDB: Analytics and historical archives
- NAS: Shared document and data storage
- Flask: Application backend
- Leaflet: GIS user interface

## Development Status

Phase 10: Initial development environment setup.

## Data and Security

This repository contains source code, documentation,
database migrations, and synthetic test data only.

No production databases, personal information,
confidential infrastructure information, or internal
municipal documents are included.
